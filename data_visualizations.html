Adding discrete color to an area chart

I first saw this type of chart on intervals.icu. It is used to make it easy to quickly spot power outputs in different "power zones". Power zones are a good way to determine what was the training effect for the workout: aerobic, threshold, anaerobic, or neuromuscular. I like how this chart makes it easy to see the power for each section without needing to read off the number on the y-axis.

This is a tutorial on how to create a chart with area and line color depending on the y-value. I worked on this plot while learning D3.js for the first time, about 3 years ago. I hope this will be helpful for others!

The image below shows a screenshot from intervals.icu: the top panel is the raw power chart, and the bottom panel is a 30-second moving average of power data with the colors of the area under the curve are based off power zones. This is the chart we will recreate here. Let's get started!

The Data

In order to reproduce this power chart, we need two sets of data:

  • Power data time series
  • Power zone boundaries

I can download my activity data from Garmin in a .fit format. I did all the data cleaning and processing in Python. In order to extract the power data from the .fit file, I used python-fitparse package. 

import os
import re
from numpy import nan
import pandas as pd
import fitparse

Make sure you saved your .fit file in the same working directory. Here's how you would read it: 

fitfile = fitparse.FitFile("19231612591_ACTIVITY.fit")

There's a bit of "manual" work required to extract the time series data: 

# Create an empty list where we will append a dictionary for each time stamp in the data
data_parse = []

# Loop through data entries. File contains a "message" for each data entry it "receives" from the Garmin device.
for record in fitfile.get_messages('record'):
	# Create an empty dictionary for each time stamp
	data_row = {}
	for data in record:
		if not re.search('unknown_', data.name):
			data_row[data.name] = data.value
	data_parse.append(data_row)

Create 2 new columns which will be our x and y axes in the plot. Then export the data as .csv which we'll read in with JavaScript. 

raw_df["elapsed_time"] = raw_df.timestamp - raw_df.timestamp.iloc[0]
raw_df["smooth_power"] = raw_df["power"].rolling(30, center=True, min_periods=1).mean()
power_df = raw_df[["elapsed_time", "power", "smooth_power"]].copy().fillna(0)
power_df.to_csv("cycling_activity.csv", index=False)

The data extraction part is over, and now the fun part begins! Let's get out of Python and bring this data to our JavaScript code. Since I'm just building a static webpage here and I don't care about this data being public, I'll just save csv values in a JS function as a string. Then I'll use csvParse() function from D3.js to turn it into a JS object. 

export function get_data () {
	const csv_string = (
        `elapsed_time,power,smooth_power
        0,0.0,406.7142857142857
        1,0.0,395.53333333333336
		...
		1612,0.0,115.94117647058823
		1613,0.0,96.125`);

    return d3.csvParse(csv_string, d3.autoType);
}

Note that the `...` is the middle of the data above is just to shorten the function here. :)
