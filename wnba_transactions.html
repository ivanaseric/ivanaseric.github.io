WNBA Player Movement

You know how every NBA trade deadline, you start losing track of which player is on which team? Then the same thing happens in the free agency? This wasn't a big issue in the WNBA, but with every non-rookie player (except for 2) being unrestricted free agent, there is bound to be a lot of movement!

I built this data visualization to make it easier to track who is on which team, and how they got there.
