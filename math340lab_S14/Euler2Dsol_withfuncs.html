Assignment due Tuesday 5pm

Use a change of variables to convert the 2nd order differential equation to a system of first order differential equations, and then solve this system using Euler's method.

This equation describes a damped oscilator (e.g. mass on a spring). Vary the constant coefficients in the equation, and see how the solution behaves. Try to produce 3 qualitatively different solutions and describe what kind of oscilations are obtained.

Solution

% a y'' + b y' + c y = 0
% coefficients are saved in a matrix "coeffs", this makes it easy to run 3
% different cases by using one loop

clear all; clc;
coeffs = [4 1 2; 4 0 2; 1 1.5 1];
PlotTitle = {'Damped system', 'No damping - keeps oscilating', 'Overdamped system'};

for i = 1: length(coeffs(:,1))

    [t , x] = euler2_withCoeffs(@systemODE, 0, [6; -1], 0.01, 50, coeffs(i,:));
    figure(i)
    plot(t, x(:,1))
    title(PlotTitle{i})
    xlabel('t'), ylabel('y')

end

euler2_withCoeffs
function [x, y]=euler2_withCoeffs(f, x0, y0, h, b, coeffs)
% this is a special case of Euler function that passes coefficients to
% "systemODE.m" for the Math 340 Lab "Euler's method for a system" (Spring 2014)
    x(1) = x0;       y(1,:) = y0;
    n = (b-x0)/h;
    for i = 1:n
        x(i+1) = x0 + i*h;
        y(i+1,:) = y(i,:) + h.*f(x(i),y(i,:),coeffs)';
    end
end

systemODE
function dxdt = systemODE(~, x, coeffs)
    a = coeffs(1);      b = coeffs(2);     c = coeffs(3);
    dxdt = zeros(2,1);
% dx1/dt
    dxdt(1) = x(2);
% dx2/dt
    dxdt(2) = -(c/a).*x(1)  -(b/a).*x(2) ;
end
