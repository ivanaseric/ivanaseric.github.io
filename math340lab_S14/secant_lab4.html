MATLAB trick #1

Download the line_fewer_markers.m function from Mathworks website

( http://www.mathworks.com/matlabcentral/fileexchange/42560-linefewermarkers/content/line_fewer_markers/line_fewer_markers.m )

Save it in "Current directory" or add the directory where you saved it to the path to make sure you can use it. Use this for plots with multiple graphs when printing in black-and-white.

For example:

clear all
clc
x = linspace(-3,3,100);
line_fewer_markers(x,x.^2,10,'o','MarkerSize',6,'MarkerFaceColor','b');
line_fewer_markers(x,2.*x,10,'^','MarkerSize',7,'MarkerFaceColor','b');
legend('x^2','2x'), legend('Location','SouthEast')
xlabel('x'), ylabel('f(x)')
title('You can tell the lines appart in B-W')
grid on

MATLAB trick #2 - Save some time

Download the publishdepfun.m function from Mathworks website

( http://www.mathworks.com/matlabcentral/fileexchange/33476-publish-dependent-and-called-functions)

Save it in "Current directory" or add the directory where you saved it to the path to make sure you can use it. You can use this function to publish the code and function you call in that code. Simply type

>> publishdepfun('your_m-file.m',[],{includeed_functions},{excluded_functions})

in command window. For example:

>> publishdepfun('secant_lab4.m',[],{'secant.m'},{'line_fewer_markers.m'})

This way function 'line_fewer_markers.m' will not be published, but 'secant.m' will be.

Solution - Secant Method

clear all
clc

% define the function:
f = @(x) sin(x) - 5.*x.^2;

% initial guesses - first root
x0 = -1;  x1 = -0.5;

Error = 1E-6;   iter_max = 50;

[app_root,secant_xn]=secant(f,x0,x1,Error,iter_max);
fprintf('The root of the function is %10.6f\n',app_root)
app_error = abs(secant_xn(2:end) - secant_xn(1:end-1));   % calculate approximated error = \|x_{n+1} - x_n\|

figure(1)
plot(1:length(secant_xn)-1,app_error) % Plot error vs numer of iterastions
xlabel('n'), ylabel('E_n')
title('Secant method error - first root')


% initial guesses - second root
x0 = 0.1;  x1 = 1;

Error = 1E-6;   iter_max = 50;

[app_root,secant_xn]=secant(f,x0,x1,Error,iter_max);

figure(2)

Solution Fixed point iteration

Consider the following equation

Use a fixed point iteration scheme to find the root. On the same plot, plot the approximated error () and Aitken's error estimate vs number of iteration. (Use line_fewer_markers.) Include legend, axis labels and title.

clear all
clc
clf
g = @(x) 2 + 2.*atan(x);

Error = 1E-6;   iter_max = 20;
xn = 0;
xn_p = g(xn);
iterates(1) = xn;
iterates(2) = xn_p;
iter = 2;

while abs( xn - xn_p ) >= Error
    xn = xn_p;
    xn_p = g(xn);
    iter = iter+1;
    iterates(iter) = xn_p;
    if iter >= iter_max
        fprintf ('Maximum number of iterates (%d) reached, try bigger iter_max. app_root set to inf.\n', iter_max)
        app_root=inf;
        break;
    end
end
app_root = xn_p;

fprintf('The root of the function is %10.6f\n',app_root)
app_error = abs(iterates(2:end) - iterates(1:end-1));   % calculate approximated error = \|x_{n+1} - x_n\|
lambda = (iterates(3:end) - iterates(2:end-1))/(iterates(2:end-1) - iterates(1:end-2)) ;
Aitken_error = (lambda/(1-lambda))*(iterates(3:end) - iterates(2:end-1));


line_fewer_markers(1:length(app_error),app_error,10,'o','MarkerSize',6,'MarkerFaceColor','b'); % Plot error vs numer of iterastions
xlabel('n'), ylabel('E_n')
title('Fixed point iteration method error')
