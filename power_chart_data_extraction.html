Extracting Data from Fitness Files Using Python

This is a supplement to my article about data visualization of cycling data. I'll show you here how to extract data from a .fit file.

To get started I downloaded one activity data from my fitness tracking account (Garmin in my case) in a .fit format. This is a binary format, and it takes a bit of processing to get the data in a usable form that most of us are used to.

In order to extract the data I needed (time and power), we'll use python-fitparse package. Then, we'll use pandas for some light data transformations. 

import pandas as pd
import fitparse

Now, we'll read the .fit file with fitparse using the FitFile() function and passing in the file path and name of our file. Since I saved the .fit in the same directory as my Python code is in, I only need the file name for the path. If you saved the file in a different location on your computer, make sure to include the full path.

There's a bit of "manual" work required to extract the time series data from the activity. The .fit file contains messages: one for each data entry received from the sensor, in this case a power meter on my bike. There are many different fields, i.e. message names saved in the file. Here, we will only extract the timestamp and power, but I encourage you to explore other data that's recorded in your workout activities. 

fitfile = fitparse.FitFile("activity.fit")
data_parse = []

for record in fitfile.get_messages('record'):
data_row = {}
for data in record:
if data.name in ["timestamp", "power"]:
    data_row[data.name] = data.value
data_parse.append(data_row)

raw_df = pd.DataFrame(data_parse)

Now that we have the data extracted, we'll do a bit of transformations. First, for my purpose, I don't care about the exact time and date of each data entry, I only care about how much time elapsed from the start of the workout. We will create elapsed_time column in our data by subtracting the start time from all timestamps. Then we'll convert it to seconds. We will also need to transform the power data into a 30-second moving average. 

raw_df["elapsed_time"] = (raw_df.timestamp - raw_df.timestamp.iloc[0]).apply(lambda x: x.seconds)
raw_df["smooth_power"] = raw_df["power"].fillna(0).rolling(30, center=True, min_periods=1).mean()
raw_df.drop("timestamp", axis=1, inplace=True)

That's how you extract and preprocess data from a .fit file!
